
# Campus Connect

## 1. Project Purpose

Campus Connect is a student-focused mobile application designed to help students stay connected with their campus community. It aims to provide convenient access to useful campus information and student services through one mobile application.

## 2. Target Users

The target users of Campus Connect are:
- College students
- Students who need access to campus information
- Members of the campus community

## 3. Planned Features

The planned features of Campus Connect include:

1. Home Dashboard - Provides an overview of the application.
2. Navigation - Allows users to move between different sections.
3. Forms and State - Allows users to enter and manage information.
4. API and Cloud Data - Connects the application to online services.
5. User Authentication - Supports secure user accounts and login.
6. Local Storage - Saves selected information on the device.
7. Offline Support - Allows access to selected features without an internet connection.
8. Device Integration - Explores supported mobile device features.
9. Testing - Checks the functionality and reliability of the application.

## 4. Development Tools

- React Native
- Expo
- JavaScript / TypeScript
- Node.js and npm
- Visual Studio Code
- Git

## 5. Project Continuity

Campus Connect will be developed continuously from Week 1 to Week 18. All future activities and features will be integrated into the same project folder and repository.
